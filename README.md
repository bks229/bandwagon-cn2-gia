# 搬瓦工哪个套餐好：从 $49.99 入门款到香港 CN2 GIA，按预算和用途一次选对

搬瓦工哪个套餐好，取决于两件事：你打算花多少钱，以及你对国内连接质量的要求。先把结论放在最前面——大多数人适合 **CN2 GIA-E 系列的最低配**：2核 CPU、1GB 内存、20GB SSD、每月 1TB 流量、2.5Gbps 带宽，季付 $49.99，年付 $169.99，买完还能在十几个机房之间免费切换。预算压到极限，就选 $49.99/年的普通线路款；对延迟有硬性要求、预算也跟得上，再往香港和日本机房看。

为什么是这个答案？搬瓦工（BandwagonHost）是加拿大 IT7 Networks 旗下的 VPS 品牌，2012 年推出，核心卖点始终是线路。CN2 GIA 是中国电信面向企业级用户的优质回程线路，晚高峰不容易拥堵丢包，搬瓦工是国内外较早大规模提供这条线路的商家之一，靠这一点在 VPS 圈积累了多年口碑。代价也明摆着：便宜套餐走不了这条线路，而且它的入门价从早年的 $3.99/年 一路涨到了如今 $49.99/年，“便宜”这个词早就不适合它了，它卖的是线路和稳定。

下面按这个顺序展开：先讲清楚最容易搞混的计费周期问题，然后给出目前在售的全系套餐价格总表，再按用途给出具体建议，最后是机房选择规则、购买限制和优惠码现状。

## 先分清两个 $49.99：一个年付，一个季付

搜搬瓦工套餐的人，十有八九会被同一个数字搞晕：$49.99。这个价格同时挂在两个套餐上，计费周期却完全不同——KVM 和 CN2 普通线路的 $49.99 是**年付**，CN2 GIA-E 最低配的 $49.99 是**季付**，GIA-E 年付要 $169.99。很多文章把两个价格并排列出来，却不点破这一点，读者很容易以为 GIA-E 最低配也是一年五十刀。

换算一下就知道差距了。GIA-E 最低配按季付买一年要 $199.96，直接年付 $169.99，能省下约 $30，所以确定要用就选年付。它和 $49.99/年 的普通款差 $120/年，换来的是三网 CN2 GIA 回程、2.5Gbps 带宽（普通款是 1Gbps），以及进入优化线路机房池的资格。

这两个套餐的分工其实很清楚。普通款适合学 Linux、跑脚本、搭个不在意速度的小服务；只要“国内访问速度”出现在你的需求清单里，GIA-E 基本是绕不开的选项。后面选机房的部分会解释为什么普通款后期补不了这条线。
